# Server Manager
The Vincent OS Server Manager is a TUI tool made with Terminal.Gui to manage your server easily.

## Installation
Server Manager should be already installed if you are using Vincent OS Server.

If you want to build it from source you should follow these steps:
1. Clone the repository
2. Open the solution in Visual Studio
3. Build the solution

## Contribute
Server Manager is open to all contributions! You can read more at the CONTRIBUTE.md file.
